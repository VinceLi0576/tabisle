先分清三件事 · 换新浏览器怎么开始

同步让几台浏览器的书签保持一致。每分钟自动跑一次，把两边的新增和修改合到一起，不用你点。云端只存一份「最新版」（backups/sync/state.json）。
备份留住历史，好回头。每小时往云端 backups/ 目录归档一份完整快照（坚果云自己再保留一个月历史）；本机只留几份「保险丝」——删除前、恢复前、手动、AI 执行前各留最近 5 份，外加每天一份留底。
恢复回到某一份备份的样子。在下面「版本与恢复」里挑一份，先预览会改什么，再确认。恢复前会自动再留一份保护副本，怕改错。

换一台新浏览器，怎么开始

  1. 装好插件，到这一页「连接坚果云」填同一个账号、同一个目录，点验证。
  2. 点一次「立即同步」。第一次是「合并」不是「覆盖」：这台原有的书签和云端的都会留下（所以想干净地接云端，就先让这台的书签栏空着）。这一步一定要人点，自动同步遇到「第一次」会停下来等你。
  3. 之后就不用管了：每分钟自动同步。

两台浏览器来回切换

不需要「先下载、改完再上传」这套动作。你在哪台改，一分钟内另一台就跟上；反过来一样。唯一要留意的：别在同一分钟里、在两台上改同一条书签的同一个字段——那才叫冲突，自动同步会保留云端那一份。新增、删除、挪位置、改不同的条，两边都会合起来，互不打架。

顶栏那颗药丸只是把这一切的状态告诉你；点它就是进这一页。

尚未读到这台浏览器已保存的备份设置，暂时不能保存或连接，以免把空白覆盖上去。这不表示账号或密码已被删除——请点上面的「重新加载此页面」。未保存的输入会保留。

正在读取…

立即备份 / 上传

保留本机版本。云备份已启用时，也向同一坚果云目录新增快照，不会因此把其他电脑的书签导入本机。

下载 / 导入 JSON 预览

下载只把备份保存成文件；导入只生成恢复预览，都不会直接覆盖书签。

预览恢复 / 确认恢复

确认后按指定版本修改书签栏，包括新增、删除与移动。先自动保存保护副本；已开启的 Google 书签同步可能把恢复结果传播到其他设备。

本机副本随扩展存放，卸载扩展或删除浏览器资料可能丢失。手动备份和恢复前保护会保留副本，即使选择纯本地。

连接后，点击「读取云端历史」。

云端历史由独立快照组成，不依赖坚果云文件的历史版本。旧快照不会自动删除；本页不会删除云端文件。

备份方案

正在读取…
备份方案
Chrome / Edge 的账号同步与坚果云同步，分别在哪里开关？
两套独立开关，选择备份方案不会改变浏览器账号同步

Chrome 的 Google 账号同步负责 Chrome 之间的书签；Edge 的 Microsoft 账号同步负责 Edge 之间的收藏夹。本插件通过坚果云连接不同浏览器，同时同步备注和标签。

查看 Chrome：同步设置 → 管理您的同步数据 → 自定义同步 →「书签」。
查看 Edge：设置 → 个人资料 → 同步 →「收藏夹」。只调整这一项即可，密码等项目可继续同步。

本插件无法直接读取或控制浏览器账号的书签同步开关；实际状态请以上面的浏览器设置为准。关闭 Edge 的收藏夹同步，不会关闭 Chrome 的 Google 书签同步，也不会自动关闭本插件的坚果云同步。

两个都开会怎样？两套机制会同时处理书签修改与删除。可以并存，但不代表所有浏览器组合已经验证无冲突。新浏览器首次接入建议暂关该浏览器的书签 / 收藏夹账号同步，完成坚果云合并和核验后，再决定是否开启并存。

使用浏览器自己的账号

在同步设置中开启「书签 / 收藏夹」。同步也会传播删除，因此建议继续保留下面的本机备份。

关闭同步后，资料仍可正常使用

请在浏览器设置中关闭书签同步，并暂停其他已安装的同步工具。选择此方案不会删除书签、备注或已有历史；清理本机历史另有按钮。

后台按本机计划时间触发，并由单次闹钟和每 5 分钟兜底共同检查，不要求打开本页。浏览器关闭或电脑休眠时会延后，启动或打开首页后检查补做一次。备份保存历史，自动同步每分钟检查最新版，两者独立。本机备份按用途分档保留：删除前、恢复前、手动、AI 执行前这类「保险丝」留最近 5 份；每天一份「留底」留 3 天；同步前和定时的各只留最新 1 份。历史版本这一层由云端负责，云端快照不会自动删除。选择坚果云后，验证连接成功才会启用上传。

使用说明

正在读取…

连接成功，不等于同步完成

连接已验证：账号、目录可用，允许云备份；尚不代表书签已经合并。

云备份已核验：备份文件上传后已下载核对；不会因此把云端书签应用到另一台浏览器。

本机同步已核验：本机应用完成，并与云端读回内容一致。另一台浏览器也需显示相同的版本与内容指纹，才能确认它已收到。

中断 / 待处理：云端可能已经写入，本机却只应用了一部分。此时不能认为同步成功，也不要重新整批导入或清空书签。先查看保护副本，再重新预览；若再次出现同类错误，停止重复确认，保留现场排查。

“每分钟自动跟随最新版”是本插件的独立开关。首次同步未完成时不能开启；浏览器账号同步的开关不会替代它。

多台电脑，用同一套还是各用各的？

共用同一套云端资料。账号与完整目录相同，就连接到同一份同步资料和备份历史；设备名称只标注来源。

第二台电脑如何填写
设置项如何填写作用
坚果云账号与第一台相同访问你自己的同一套云端资料。
同步与备份目录完整地址与第一台相同包括地址最后的文件夹路径。不要为了区分设备另建目录，否则会变成两套独立资料。
第三方应用密码填写该账号的有效应用密码可以沿用同一应用密码；也可以使用该账号另建的有效应用密码。密码负责验证身份，不负责区分同步资料。
设备名称自动随机生成，可自行改名例如「晨光·松林·白鹭」。首次生成后保存，不会每次打开都换名。名称仅标注来源，不会改变同步账号或目录。
自动备份 / 自动同步每台浏览器分别设置连接成功后选择备份频率；每台都完成一次手动同步，才能分别开启自动同步。

同一台电脑的普通 Chrome 与测试 Chrome，也各自保存连接设置。扩展代码可以共用，账号、密码、设备名称和自动开关不会因为共用代码而自动复制。

设备改名后，旧备份也会一起改名吗？

例如把 A 改成 A1：保存后，本机设置与以后新建的备份使用 A1；以前保存的备份仍显示当时的 A，其他浏览器的名字保持不变。上传以前的旧备份，也保留它原来的名字。

改名不会新建同步目录，不会重新导入或复制书签，也不会中断已经配置的同步。历史备份保留原样，恢复旧备份也不会把本机设备名改回去。

自动名称采用随机词语组合，不带日期或数字尾巴。随机名字可能偶然相同，但不会因此合并设备；每个安装还保存独立标识，改名时保持不变。名称仅用于让你认出备份来源。

按这个顺序开始使用

下面配置的是本插件与坚果云之间的同步。新浏览器首次接入时，建议先在该浏览器设置中暂关「书签 / 收藏夹」账号同步，完成核验后再决定是否同时开启。

第一台：选择资料最完整的浏览器

  1. 设备名称已自动起好，可直接沿用；想换名字时修改后点击「保存方案」。
  2. 填写坚果云账号、应用密码和专用目录，点击「验证连接并启用云备份」。这一步启用备份上传，还不会合并书签。
  3. 在「多设备同步」中点击「立即同步」。云端没有共享资料时，将本机资料作为起点上传。
  4. 同步成功后自动开启「每分钟自动跟随最新版」，无需逐条确认。

第二台及后续电脑：连接同一套资料

  1. 安装书签首页并打开本页，会自动获得本机名称。可直接沿用，或改成自己容易辨认的名称后保存。
  2. 填写第一台使用的同一账号、同一完整目录，以及有效应用密码，验证连接。
  3. 点击「立即同步」。本机为空时下载云端资料；已有书签会参与合并，同一项存在冲突时保留云端版本。
  4. 等待读回核验成功，之后这台浏览器自动跟随共同版本。
备份与共同版本有什么区别？

历史备份保存的是某一时刻的版本，共享同步资料保存的是各设备共同维护的内容。已有历史备份不会自动成为同步起点；请先在资料最完整的浏览器完成首次同步。

如果只想在另一台电脑留备份，验证连接后点击「立即备份」即可，不必执行同步。只有你希望两台电脑的书签、备注和标签合并并持续保持一致时，才点击「立即同步」。

以后新增、修改、删除，会发生什么？

完成首次同步后，书签首页按上次共同版本合并两端变化。新增与修改会传到其他已配置的浏览器，删除也会传播；同一字段有冲突或旧内容回流时，以云端版本为准，不要求逐条选择。写入前自动保存保护副本；网络错误、并发变化或核验失败仍会停止本次操作并显示原因。

Google 书签同步与坚果云同步是两条独立通道，都能修改浏览器书签。可以并存，但不能保证任何交错操作都没有冲突。Google 书签同步不传递书签首页的备注、标签和颜色，这些由书签首页同步。

自动同步需要浏览器运行。每台浏览器分别完成首次同步、首次同步成功后自动开启持续同步；后台每分钟检查一次，设备之间随机错开 5 到 25 秒。显示偏好和文件夹折叠状态各自保留。
