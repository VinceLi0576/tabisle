# 书签首页 · TabIsle

**让书签成为你的新标签页。**

TabIsle 是一个 Chrome 新标签页扩展，把浏览器书签栏展开成可以直接浏览、整理和编辑的首页。

当前版本：**v0.10.0**；首个公开版本为 v0.9.2。需要 **Chrome 141 或更新版本**。
目前通过加载本地扩展安装，界面中的扩展名称仍为「书签首页」。

----------------

## WHY · 为什么做

收藏一个网址很容易，再次找到它却经常要翻好几层文件夹。
网页原本的标题又长又杂，即使保存了很多书签，也未必愿意每天打开来看。

我们希望书签成为日常真正用得上的入口。
打开新标签页，就能看见自己整理的内容；需要时再展开详情，为链接补上容易记住的名字、说明和标签。

你已有的收藏和文件夹，是这个首页的起点。

## HOW · 怎么做到

### 直接使用浏览器书签

TabIsle 读取浏览器书签栏，修改书签名称、网址、位置和顺序时，也写回浏览器书签。
可使用浏览器账号同步，也可由书签首页直接通过坚果云同步；浏览器账号同步可以按需保留。

显示名、说明、标签和分组颜色保存在扩展本机存储中。
这些附属信息可通过坚果云与书签一起同步，也可通过导入导出或完整备份迁移。

### 按层级看清内容，按需要展开编辑

保留原有文件夹层级，每深入一级固定缩进 20 像素。
层级竖线依次使用蓝、绿、橙、紫，之后循环；同一条竖线按实际层级分成对应段数。
左侧导航展示前两级，更深的内容在主区域查看。

点击文件夹标题左侧的箭头，可以折叠整组内容，并记住本机展开状态。
已有的 Inbox 文件夹会高亮标记为「收纳」，它和内部子文件夹默认收起；不会自动创建或移动书签。
搜索包含折叠内容，导航定位和标签筛选会临时展开相关文件夹。

详情栏平时收起。
点击书签右侧箭头，Chrome 原生侧栏展开，首页随之缩窄；再点同一条书签的箭头即可收起，点击其他书签则切换详情。

### 让整理可以回头

本机历史定期保存书签栏与附属数据，也支持手动备份和下载 JSON。
恢复前先展示变化清单，再保存一份当前状态作为保护。

可选的坚果云 WebDAV 功能会上传独立的历史快照。
每份快照使用不同文件名，便于查找和恢复过去的状态。

## WHAT · 现在可以做什么

| 功能 | 用法 |
| --- | --- |
| 书签首页 | 按文件夹浏览链接，搜索内容，使用标签筛选 |
| 层级与颜色 | 查看多层文件夹，自定义分组颜色，悬停时联动高亮同主域链接 |
| 整理文件夹 | 拖动排序、调整归属；防止文件夹被放进自身或后代 |
| 详情编辑 | 修改网址、书签名、所在文件夹，以及显示名、说明、标签和图标 |
| 编辑草稿 | 在当前浏览器会话内，收起侧栏或切换书签后继续未保存的修改 |
| 备份与恢复 | 本机历史、JSON 导入导出、恢复预览和恢复前保护 |
| 可选云端备份 | 向坚果云上传快照、读取历史并预览恢复 |

AI 入口目前属于实验功能，需要自行配置服务，目前仍在探索适合书签整理的使用方式。

**废弃项固定靠后。** 名称为「废弃」的标签用于标记不再优先使用的内容。
书签和文件夹在各自同级范围内排到末尾，其他项目保持原有相对顺序；搜索结果中的废弃项也排在正常项之后。
文件夹可通过右键标记或取消废弃，其内部内容在搜索与标签筛选中按所属文件夹的标记处理。
这项规则只调整展示，不移动或删除浏览器书签；取消标记后，按浏览器保存的顺序显示。

## 开始使用

下载或克隆本项目，把源代码保存在固定目录。
然后在 Chrome 地址栏打开：

```text
chrome://extensions
```

开启「开发者模式」，选择「加载已解压的扩展程序」，选中包含本项目清单文件的目录。
打开新标签页即可使用；其他接管新标签页的扩展可能需要停用。

### 编辑一个书签

点击左侧网站 logo 即可复制完整网址，成功时会出现勾号和「网址已复制」提示。
首页、搜索结果和最近访问都支持；点击名称仍然打开网页。

点击书签右侧的箭头，侧栏从上到下依次展示网址、书签名、显示与备注、所在文件夹。

**书签名**是收藏网页时带入的标题，可以修改。
它不代表扩展会在你每次更换网址后自动抓取网页标题。

**显示名**是你自己起的简短名称，建议 4～6 个字，只影响首页展示。
说明用于补充用途，彩色标签用于整理和筛选。

书签名、网址和所在文件夹需要点击「保存」。
显示名、说明、标签和图标会自动保存。
相同标准化网址的书签共用这份附属信息。

### 留一份浏览器以外的备份

当前真实 WebDAV 测试：完整备份上传、下载核对和月份列表通过；已适配并验证坚果云的创建防覆盖与版本条件写入。
实际多设备同步仍需用户预览确认，不因连接测试自动开启。
账号与目录验证成功，不等于已有完整云备份，也不等于双向同步已完成。

从工具栏进入「备份与恢复」，可以立即备份或下载 JSON。
页面提供坚果云、浏览器账号和纯本地三个方案。默认推荐坚果云，验证连接前不会上传。
本机自动备份可选每小时、每 3 小时、每天、每 7 天或每 30 天；纯本地关闭自动备份和上传。
浏览器关闭期间无法执行；启动和打开首页时会检查补备份。

本机最多保留最近 20 份，超过约 6 MB 时优先移除旧版本。
卸载扩展或删除浏览器资料可能丢失这些副本，因此建议另存下载文件，或配置可选的坚果云备份。

完整备份覆盖**书签栏**及其附属数据和显示偏好，其他书签根目录不在此次恢复范围内。
恢复会修改真实书签；已有同步工具也可能把这些修改同步到其他设备。

## Git、同步和 WebDAV 各管什么

| 工具 | 负责的事情 |
| --- | --- |
| Git / GitHub | 保存和分享扩展源代码、说明文档与测试 |
| 浏览器账号同步 | 按浏览器配置同步原生书签 |
| 书签首页 WebDAV 同步 | 直接合并各设备书签、备注、标签与分组颜色 |
| TabIsle 本机备份 | 保存可预览、可恢复的历史快照 |
| 坚果云 WebDAV | 可选保存浏览器以外的历史快照 |

WebDAV 功能代码属于项目源代码。
用户的账号、应用密码、API Key、真实书签和备份文件不属于公开仓库内容。

当前 WebDAV 实现只支持坚果云官方地址，需要用户配置自己的账号和应用密码，并授予访问权限。
新快照按月份存放，支持选择月份查看和恢复；旧根目录快照仍可读取。
快照与当前同步文档分开存放，云端旧快照目前不会自动清理。

页面内提供注册、应用密码、连接验证和书签首页直接同步引导，无需安装其他同步扩展。
首次预览合并双方内容，之后可开启每分钟自动跟随最新版；冲突或大量删除会暂停，等待确认。
免费坚果云当前每月上传 1 GB、下载 3 GB，具体以官方权益为准。
完整步骤、额度来源及同步边界见 [备份与同步](docs/备份与同步.md)。

## 数据与网络访问

无需注册 TabIsle 账号即可使用本机书签功能。
扩展使用浏览器书签、存储、历史记录、图标、定位、侧栏和定时任务等权限提供相应功能。

天气组件会调用 IP 定位、天气与地理编码服务。
网站图标可能从 Google 图标服务获取；自定义远程图片会访问对应地址。

配置并使用 AI 时，会向所选服务发送相应请求和上下文。
启用坚果云上传后，备份中的书签和附属数据会发送到用户配置的目录。

AI Key 和坚果云应用密码保存在扩展本机存储中，不进入导出的备份。
本机存储不等同于加密密码保险箱；下载的备份同样包含个人书签，应自行妥善保管。

## 开发与验证

扩展源文件可以直接加载，无需先安装依赖或执行构建。
核心行为测试使用 Node.js 内置测试运行器：

```sh
node --test tests/*.test.cjs
```

测试通过模拟书签和网络验证恢复、草稿、冲突及 WebDAV 请求，不修改真实书签。
真实云端账号的连接与上传还需要在自己的环境中验证。

开发流程和提交约定见 [贡献指南](CONTRIBUTING.md)，版本变化见 [更新记录](CHANGELOG.md)。

贡献时请使用虚构测试数据。
提交前检查变更内容，不要加入真实书签、凭据、个人备份或本机协作记录；忽略规则无法删除已经进入 Git 历史的数据。

更多当前交互和备份细节见 [使用说明](说明.md)。

### 自动备份与同步核验

新安装默认每小时备份，可选每 3 小时、每天、每周或每月；原有频率继续保留，需在设置中保存新选择。每台浏览器独立保存下次执行时间，每轮在所选频率后额外随机延迟 30 秒到 5 分钟。页面显示倒计时，重新打开不会重置。后台按计划触发，并每 5 分钟兜底检查；休眠或关闭期间不执行，恢复后先随机错峰再补做一次。

持续同步每分钟检查一次，并在设备间随机错开 5 到 25 秒；云备份重试间隔为 5 分钟加随机错峰。无变化时只用 WebDAV `HEAD` 检查版本标识，发现新版或本机修改后才下载、三方合并并上传，减少流量。随机错峰不能保证绝不重叠，云端条件写入仍防止版本覆盖。云备份上传后重新下载核对完整内容；同步只有在云端读回与本机应用均核验一致后，才记录成功回执。回执显示时间、变更数量、云端版本和内容指纹。另一台浏览器需要完成同版核验，不能仅凭当前浏览器的成功判断它已收到。

本地解压安装不会自动热更新。更新目录文件后，各浏览器分别重新加载扩展，并刷新旧页面；不需要卸载，已保存数据保留。
