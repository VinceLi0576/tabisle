# 签屿 · TabIsle

**让书签成为你的新标签页。**

TabIsle 是一个 Chrome 新标签页扩展，把浏览器书签栏展开成可以直接浏览、整理和编辑的首页。

首个公开版本：**v0.9.2**。需要 **Chrome 141 或更新版本**。
目前通过加载本地扩展安装，界面中的扩展名称仍为「书签首页」。

----------------

## WHY · 为什么做

收藏一个网址很容易，再次找到它却经常要翻好几层文件夹。
网页原本的标题又长又杂，即使保存了很多书签，也未必愿意每天打开来看。

我们希望书签成为日常真正用得上的入口。
打开新标签页，就能看见自己整理的内容；需要时再展开详情，为链接补上容易记住的名字、说明和标签。

你已有的收藏和文件夹，是这个首页的起点。

## HOW · 怎么做到

### 直接使用浏览器书签

TabIsle 读取浏览器书签栏，修改书签名称、网址、位置和顺序时，也写回浏览器书签。
现有浏览器同步或 floccus 可以继续负责书签同步。

显示名、说明、标签和分组颜色保存在扩展本机存储中。
这些附属信息通过导入导出或完整备份迁移，目前不会自动跟随书签同步到其他设备。

### 按层级看清内容，按需要展开编辑

保留原有文件夹层级，每深入一级固定缩进 20 像素。
层级竖线依次使用蓝、绿、橙、紫，之后循环；左侧导航展示前两级，更深的内容在主区域查看。

详情栏平时收起。
点击书签右侧箭头，Chrome 原生侧栏展开，首页随之缩窄；再点同一条书签的箭头即可收起，点击其他书签则切换详情。

### 让整理可以回头

本机历史定期保存书签栏与附属数据，也支持手动备份和下载 JSON。
恢复前先展示变化清单，再保存一份当前状态作为保护。

可选的坚果云 WebDAV 功能会上传独立的历史快照。
每份快照使用不同文件名，便于查找和恢复过去的状态。

## WHAT · 现在可以做什么

| 功能 | 用法 |
| --- | --- |
| 书签首页 | 按文件夹浏览链接，搜索内容，使用标签筛选 |
| 层级与颜色 | 查看多层文件夹，自定义分组颜色，悬停时联动高亮同主域链接 |
| 整理文件夹 | 拖动排序、调整归属；防止文件夹被放进自身或后代 |
| 详情编辑 | 修改网址、书签名、所在文件夹，以及显示名、说明、标签和图标 |
| 编辑草稿 | 在当前浏览器会话内，收起侧栏或切换书签后继续未保存的修改 |
| 备份与恢复 | 本机历史、JSON 导入导出、恢复预览和恢复前保护 |
| 可选云端备份 | 向坚果云上传快照、读取历史并预览恢复 |

AI 入口目前属于实验功能，需要自行配置服务，目前仍在探索适合书签整理的使用方式。

## 开始使用

下载或克隆本项目，把源代码保存在固定目录。
然后在 Chrome 地址栏打开：

```text
chrome://extensions
```

开启「开发者模式」，选择「加载已解压的扩展程序」，选中包含本项目清单文件的目录。
打开新标签页即可使用；其他接管新标签页的扩展可能需要停用。

### 编辑一个书签

点击书签右侧的箭头，侧栏从上到下依次展示网址、书签名、显示与备注、所在文件夹。

**书签名**是收藏网页时带入的标题，可以修改。
它不代表扩展会在你每次更换网址后自动抓取网页标题。

**显示名**是你自己起的简短名称，建议 4～6 个字，只影响首页展示。
说明用于补充用途，彩色标签用于整理和筛选。

书签名、网址和所在文件夹需要点击「保存」。
显示名、说明、标签和图标会自动保存。
相同标准化网址的书签共用这份附属信息。

### 留一份浏览器以外的备份

从工具栏进入「备份与恢复」，可以立即备份或下载 JSON。
默认每天检查并生成本机备份，浏览器关闭期间无法执行；启动和打开首页时会检查补备份。

本机最多保留最近 20 份，超过约 6 MB 时优先移除旧版本。
卸载扩展或删除浏览器资料可能丢失这些副本，因此建议另存下载文件，或配置可选的坚果云备份。

完整备份覆盖**书签栏**及其附属数据和显示偏好，其他书签根目录不在此次恢复范围内。
恢复会修改真实书签；已有同步工具也可能把这些修改同步到其他设备。

## Git、同步和 WebDAV 各管什么

| 工具 | 负责的事情 |
| --- | --- |
| Git / GitHub | 保存和分享扩展源代码、说明文档与测试 |
| 浏览器同步 / floccus | 按各自配置同步浏览器书签 |
| TabIsle 本机备份 | 保存可预览、可恢复的历史快照 |
| 坚果云 WebDAV | 可选保存浏览器以外的历史快照 |

WebDAV 功能代码属于项目源代码。
用户的账号、应用密码、API Key、真实书签和备份文件不属于公开仓库内容。

当前 WebDAV 实现只支持坚果云官方地址，需要用户配置自己的账号和应用密码，并授予访问权限。
快照不会覆盖 floccus 的同步文件；云端旧快照目前不会自动清理。

## 数据与网络访问

无需注册 TabIsle 账号即可使用本机书签功能。
扩展使用浏览器书签、存储、历史记录、图标、定位、侧栏和定时任务等权限提供相应功能。

天气组件会调用 IP 定位、天气与地理编码服务。
网站图标可能从 Google 图标服务获取；自定义远程图片会访问对应地址。

配置并使用 AI 时，会向所选服务发送相应请求和上下文。
启用坚果云上传后，备份中的书签和附属数据会发送到用户配置的目录。

AI Key 和坚果云应用密码保存在扩展本机存储中，不进入导出的备份。
本机存储不等同于加密密码保险箱；下载的备份同样包含个人书签，应自行妥善保管。

## 开发与验证

扩展源文件可以直接加载，无需先安装依赖或执行构建。
核心行为测试使用 Node.js 内置测试运行器：

```sh
node --test tests/core.test.cjs
```

测试通过模拟书签和网络验证恢复、草稿、冲突及 WebDAV 请求，不修改真实书签。
真实云端账号的连接与上传还需要在自己的环境中验证。

开发流程和提交约定见 [贡献指南](CONTRIBUTING.md)，版本变化见 [更新记录](CHANGELOG.md)。

贡献时请使用虚构测试数据。
提交前检查变更内容，不要加入真实书签、凭据、个人备份或本机协作记录；忽略规则无法删除已经进入 Git 历史的数据。

更多当前交互和备份细节见 [使用说明](说明.md)。
